# 项目脚手架升级

[English](project-upgrade.md) | [简体中文](project-upgrade.zh-CN.md)

`xamlnexus upgrade` 将模板来源的项目基础设施更新到当前 CLI 所带版本：

```powershell
xamlnexus upgrade --project D:\Projects\MyApp
```

新项目记录来自所选模板的所有文件，包括：

- `.github` 发布配置与工作流；
- eng 发布脚本；
- Directory.Build.props、RELEASING.md、示例更新清单；
- Common/Updates 更新基础设施；
- IXamlNexusModule 生命周期契约；
- 解决方案、工程、应用源码、XAML、资源和模板资产。

所有生成源码和配置都可定制，包括版本属性、工作流、发布脚本。基础设施内容差异产生 XN1302 警告，不使普通校验失败。userEditable 只是抑制常规基线诊断的提示，不是编辑许可；缺失必要文件仍是错误。保留原基线供升级使用，继续开发无需编辑清单或重算哈希。

## 三方合并

清单可保存精确模板基线。升级比较旧基线、本地项目和新目标模板：

- 只有模板改变时，目标替换旧文件。
- 只有用户或 Recipe 改变时，保留本地内容；本地与目标已经一致时也不重写。
- 普通 UTF-8 文本的非重叠行修改自动合并，JSON 策略为 textMerge。
- 双方对 XML 类文件（slnx、csproj、props、targets、xaml、xml、config、resw、nuspec、appxmanifest）有不同修改时，即使文本行不重叠，也检查节点对应与顺序。独立属性和子节点添加可采用 xmlMerge；文本成功不能覆盖结构冲突或不支持的结果。
- SLN 的结构回退可合并独立工程块、GlobalSection 和配置条目，策略为 solutionMerge。
- 重叠修改、目标删除用户修改的文件、需要合并的二进制或超大文本等情况保持冲突，不改项目。

需要语义合并时，注释、处理指令、CDATA、DTD、混合文本与元素内容、冲突值及歧义结构都不会被强行规范化或丢弃。目标未变或双方内容一致的无合并情况，仍原样保留本地文件。

新 SLN 使用由工程相对路径派生的确定性 GUID，重新生成不会仅因 dotnet sln add 分配随机 GUID 而造成无意义升级。结构合并拒绝无效或未知顶层 Global 内容、重复结构键，以及删除对修改、同键冲突。既有工程块内部按整体处理。

只有显式指定输出目录才导出冲突文档：

```powershell
xamlnexus upgrade --project D:\Projects\MyApp `
  --conflict-output .\upgrade-conflicts
```

导出路径保留项目相对层级并加 `.merge` 后缀，包含 LOCAL、BASE、TARGET。不会覆盖已有文件。conflict-output 不能与 dry-run 同用，因为导出会在项目事务之外写文件。

## 安全模型

清单记录路径与 SHA-256。升级先在独立临时目录生成目标，再规划完整创建／替换／删除操作。

普通校验允许内容定制；自动替换和删除仍检查预期哈希。具有可信基线快照时，可安全合并本地修改。写入前再次检查计划；文件变更与清单版本更新一起提交，异常时尝试一起回滚。

早期没有脚手架基线的项目，只能在所有候选文件与同版本模板完全一致时收养基线。工具无法区分无基线旧模板与用户修改，因此拒绝直接升级；先使用对应历史 CLI 生成或收养基线，再迁移新版本。

仅含哈希的旧清单仍受支持。其文件被修改时报告 XU2002，不猜测或覆盖。新跟踪路径被不同内容占用时也保持冲突。

稳定错误码：

- `XU10xx`：项目／目标不兼容或缺少基线。
- `XU20xx`：冲突或过期计划。
- `XU30xx`：事务或回滚失败。

XU2010 表示目标删除了用户修改文件；XU2011 表示文本或结构冲突，包括 XML 匹配歧义和顺序；XU2012 表示无法安全合并或当前合并器无法检查 XML 结构。

升级后，模板模块使用目标模块集合与元数据；已安装 Recipe 保留版本和拥有文件记录。XU2013 表示路径同时归脚手架与 Recipe 所有，即使内容一致也拒绝；XU2014 表示目标模板模块 ID 被 Recipe 占用。这两类情况同时阻止升级与基线收养，不自动转移所有权；先显式处理归属再规划。

SLNX 升级保留原解决方案格式，以 Path 识别 Project 并可保留独立工程添加。SLN 与 SLNX 转换不属于自动升级，源和目标格式必须一致。
